## Team Members

* Team member records — custom database record type for team members with profile fields (name, role, bio, image, contact)
* Category support — organise team members by department or group using `sys_category`
* Sorting — manual sorting via drag-and-drop in the backend

## Frontend Display

* Team list view — display all (or filtered) team members as a content element with configurable limit
* Team detail view — individual profile page per team member with full bio and contact info
* Category filter — optionally filter displayed team members by category in the plugin settings

## Backend Management

* Backend module — dedicated backend list module to manage all team member records
* CSV export — export team member list as CSV from the backend module

## Configuration

* FlexForm settings — per-plugin settings for list limit and optional category filter
* TypoScript configuration set — registers as a TYPO3 14 site set for clean integration
